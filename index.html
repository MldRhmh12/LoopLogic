Mengapa Algoritma Memerlukan Perulangan?

Dalam dunia nyata, komputer dirancang untuk memproses ribuan tugas serupa secara otomatis (seperti memproses nilai ratusan siswa atau mencetak tiket transaksi). Tanpa perulangan, pemrogram harus mengetikkan baris instruksi yang sama berulang kali yang menyebabkan pemborosan kode, rawan kekeliruan, dan sulit dikelola.

Prinsip Inti: Perulangan memungkinkan komputer mengeksekusi sekumpulan instruksi berkali-kali secara otomatis sampai kondisi berhenti (terminasi) terpenuhi.
Bab 1: Fundamental Algoritma

Konsep Dasar Struktur Perulangan (Looping)

Definisi Formal (Buku Teks)

Berdasarkan buku Algoritma dan Pemrograman (Rinaldi Munir, 2021), Struktur Perulangan (Repetition/Loop) adalah konstruksi algoritma yang memungkinkan sekumpulan instruksi dieksekusi berulang kali selama kondisi pengulangan bernilai benar (True) dan berhenti seketika saat kondisi bernilai salah (False).

Setiap struktur perulangan yang baik WAJIB memiliki 4 komponen fundamental:

  • Inisialisasi (Initialization): Penentuan nilai awal variabel pengendali loop.
  • Kondisi Terminasi (Condition Test): Ekspresi logika penentu lanjut atau berhentinya siklus.
  • Badan Loop (Loop Body): Kumpulan instruksi yang dieksekusi berulang.
  • Pembaruan Nilai (Modifier / Step): Perubahan variabel agar kondisi berhenti tercapai.

Contoh Penggunaan dalam Kehidupan Nyata

1. Putaran Jarum Detik Jam Dinding
Jarum detik berputar 60 kali (1 s.d. 60) untuk membentuk 1 satuan menit.
2. Pengurangan Daya Tahan Karakter Game
Setiap rintangan mengurangi daya tahan sebesar 1 poin hingga bernilai 0 (Terminasi).
3. Dispenser Mesin Vending Otomatis
Mesin mengeluarkan kaleng minuman satu per satu sampai jumlah pesanan terpenuhi.
// Pola Dasar Eksekusi Perulangan (Pseudocode / Javascript)
let hitungan = 1; // 1. Inisialisasi
while (hitungan <= 5) { // 2. Kondisi Terminasi
  console.log("Tugas ke-" + hitungan); // 3. Badan Loop
  hitungan++; // 4. Modifier / Pembaruan
}
Bab 2: Counted Loop

Struktur Perulangan FOR (Counted Loop)

Definisi & Karakteristik FOR

Perulangan FOR digunakan ketika jumlah pengulangan sudah diketahui dengan pasti sebelum perulangan itu sendiri dimulai (*Counted Loop*).

Sintaksis FOR menggabungkan inisialisasi, pengujian kondisi, dan modifier dalam satu baris pernyataan:

for (inisialisasi; kondisi; modifier) {
  // instruksi yang diulang
}
  • FOR Increment (Hitung Maju): Nilai variabel bertambah (misal: i++).
  • FOR Decrement (Hitung Mundur): Nilai variabel berkurang (misal: i--).

Contoh Nyata

1. Hitung Mundur Lampu Lalu Lintas (10 s.d. 0)

Timer lampu merah menghitung mundur 10 detik secara pasti sebelum berganti ke lampu hijau.

2. Pengurangan Nyawa Karakter Game (5 ➔ 0)

Karakter menghadapi rintangan gunung, tiap kegagalan mengurangi daya tahan hingga 0.

// Contoh Kode FOR Decrement: Pengurangan Daya Tahan
for (let nyawa = 5; nyawa > 0; nyawa--) {
  console.log(`Karakter terkena rintangan, sisa daya tahan: ${nyawa}`);
}
console.log("Daya tahan habis, siklus berhenti.");
Bab 3: Uncounted / Pre-test Loop

Struktur Perulangan WHILE (Pre-test Loop)

Definisi & Cara Kerja WHILE

Perulangan WHILE adalah jenis perulangan *Uncounted (Pre-test Loop)*, di mana syarat kondisi diuji terlebih dahulu di awal sebelum blok instruksi dijalankan.

Jika saat pertama kali diuji kondisi bernilai False, maka instruksi di dalam WHILE TIDAK AKAN PERNAH DIEKSEKUSI SAMA SEKALI (0 kali).

Peringatan Infinite Loop: Jika variabel pengendali di dalam badan WHILE tidak pernah diubah atau selalu True, program akan crash!

Contoh Penggunaan Nyata

1. Masukkan PIN Brankas / Password

Sistem akan terus meminta input PIN selama tebakan masih salah.

2. Barcode Scanner Kasir Supermarket

Kasir melakukan scan barang belanjaan pembeli satu per satu sampai keranjang kosong dan pembeli menekan Bayar.

// Contoh Kode WHILE Loop: Lempar Dadu Sampai Angka Target
let dadu = 0;
while (dadu !== 6) {
  dadu = Math.floor(Math.random() * 6) + 1;
  console.log(`Hasil lemparan dadu: ${dadu}`);
}
console.log("Target angka 6 tercapai! Loop selesai.");
Bab 4: Post-test Loop (Telah Disetujui Guru)

Struktur Perulangan DO-WHILE (Post-test Loop)

Definisi & Perbedaan dengan WHILE

Perulangan DO-WHILE adalah jenis perulangan *Post-test Loop*, di mana blok instruksi dieksekusi terlebih dahulu minimal 1 KALI, baru kemudian syarat kondisinya diuji di bagian paling bawah.

Meskipun syarat kondisi bernilai False sejak awal, blok kode di dalam do { ... } dijamin tetap berjalan tepat 1 kali.

Contoh Penggunaan Nyata

1. Menu Transaksi Mesin ATM

Menu utama selalu tampil minimal sekali. Di akhir transaksi, mesin baru bertanya: "Ingin transaksi lain? (Y/T)".

2. Konfirmasi Rematch Game

Game dimainkan minimal 1 ronde, setelah itu baru ditanyakan apakah ingin main lagi.

// Contoh Kode DO-WHILE Loop
let mainLagi = false;
do {
  console.log("Menjalankan game ronde ke-1...");
} while (mainLagi === true);
Bab 5: Advanced (Telah Disetujui Guru)

Perulangan Bersarang (Nested Loop)

Definisi Nested Loop

Nested Loop adalah struktur di mana terdapat satu perulangan di dalam perulangan lainnya (*Outer Loop* dan *Inner Loop*).

Untuk setiap 1 kali putaran pada Outer Loop, perulangan Inner Loop akan dijalankan penuh sampai selesai.

Contoh Penggunaan Nyata

1. Matriks Kursi Bioskop (Baris A-E, Kolom 1-10)

Sistem mencetak nomor kursi dari Baris A (1-10), lalu lanjut ke Baris B (1-10), dan seterusnya.

2. Papan Catur 8x8 Kotak

Memproses 8 baris horizontal yang masing-masing memiliki 8 petak kotak vertikal.

// Contoh Kode Nested Loop: Matriks Baris & Kolom
for (let baris = 1; baris <= 3; baris++) {
  for (let kolom = 1; kolom <= 3; kolom++) {
    console.log(`Posisi [${baris}, ${kolom}]`);
  }
}
